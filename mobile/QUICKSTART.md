# Quick start

The shortest version. Do these now; read [README.md](README.md) later.

## iPhone / iPad

1. Open `gamble-guard.mobileconfig` on the phone (AirDrop or Safari download) → Settings → **Profile Downloaded** → **Install**.
2. Settings → **Screen Time** → **Content & Privacy Restrictions** → on.
3. **Content Restrictions → Web Content → Limit Adult Websites** → under **Never Allow**, add the sites you use.
4. Set a **Screen Time passcode**. Hand the phone to someone you trust to type it. Do not learn it.
5. Settings → your name → **iCloud → Private Relay** → **Off**. Then try `bet365.com`; it should fail.

## Android

1. Settings → **Network & internet** → **Private DNS** → **Private DNS provider hostname**.
2. Enter `family.dns.mullvad.net` → **Save**.
3. Chrome → Settings → Privacy and security → **Use secure DNS** → use current service provider.
4. Uninstall any VPN app.
5. Try `bet365.com`; it should fail. Ask a partner to set up Family Link or an app-lock PIN you do not know.
